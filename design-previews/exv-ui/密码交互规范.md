# 密码交互规范与适配约定

本规范依据用户于 2026-10-09 明确的要求编写，约束本目录 UI 预览及后续真实应用适配。它替代 ecnu-red-22 中“快速入门密码必填”“按账户匹配保存密码”“设置页独立记住密码开关”的推断。

## 快速入门

- 快速入门按用户尚未保存数据的首次配置场景设计。
- 密码是选填项。用户不输入、不保存密码，也必须可以完成其他配置。
- 不判断“同一账户可复用的保存凭据”，不通过保存密码状态阻止完成配置。
- 快速入门本身是输入密码的模态框，记住密码选项与密码输入一起出现，不自动勾选，不因为输入了密码就默认保存。
- 密码为空时，不提交空字符串覆盖密码、不执行凭据删除，也不单独提交记住密码设置；本次没有密码操作。后续连接缺少可用密码时再询问。

## 连接与认证拒绝

1. 点击连接时，检查是否有可用密码；没有则打开统一的账户／密码模态框。
2. 有可用密码时，可开始连接。用户名和密码相对独立，修改用户名不会顺带删除、失效或隐藏已保存密码状态。
3. 仅当连接结果明确表明是用户名／密码问题导致认证拒绝时，再打开模态框，让用户确认用户名和密码。
4. 超时、网络不可达、服务异常、未知失败及其他认证因素不能被当作用户名／密码错误。后端应提供明确的分类；不能仅凭“连接失败”推断。
5. 每次弹出模态框，尤其是认证拒绝后的再次弹出，密码字段都初始化为空，隐藏输入状态。不得复用上一次临时输入，不得回填已保存密码。账户可显示当前配置值供用户确认。
6. 未记住的本次输入仅用于本次操作。下次缺少密码时重新询问，不在常驻界面保留明文或掩码值。

## 位置与模态草稿

- 设置页显示密码状态和输入／修改入口，不直接显示密码框，也不单独展示记住密码开关。
- 完整模式、极简模式共用同一居中凭据模态框；快速入门内的密码组件遵循相同规则。
- 记住密码选项只出现在包含密码输入的模态框中，属于模态草稿。
- 切换复选框不得立即写配置、清除已保存密码或改变外部状态。
- 只有用户确认后，才一次性提交本次密码和记住密码设置项（以及本次确认的用户名）。确认不记住时，持久密码处理也只能在这次确认提交中发生。
- 取消、Esc、关闭或提交完成后清空临时密码，恢复隐藏状态。取消保留原有密码和原有记住设置。
- 显隐按钮每个密码框仅一个，只能切换本次用户输入。已保存状态通过提示文本表达，不能读取密码来显示。

## 预览与真实实现边界

`shadcn-vue.html` 仅保存是否已保存密码、是否记住的演示元数据，不保存密码值，不接入真实凭据库。

真实适配应在确认操作处一次性调用凭据接口，提交成功后才更新已保存状态；提交失败不得将草稿状态当成保存成功。禁止把密码写入日志、错误、设置回读或常驻状态投影。

预览中的 `handleConnectionFailure(reason)` 展示结果分类：`credential-rejected` 才重询凭据；`network` 展示普通连接失败。组件预览提供两个独立演示按钮。真实实现须接入连接结果分类，不能把演示按钮当作真实检测。
